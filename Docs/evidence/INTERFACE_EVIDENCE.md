## Privacy and metadata review

- PNG dimensions: 1800 × 1320; RGB; 72 DPI.
- No EXIF, local filesystem path, email, phone number, portrait, or identifiable user name was found in the file metadata or visible composition.
- The image contains product copy and demo labels only; it is not a real user record.
- The package intentionally excludes `life-01.png`–`life-04.png` because those phone-screen images contain name/date UI text and are not needed for the public code path.

## Evidence boundary

This is a static design/prototype preview, not a WeChat Developer Tools capture, physical-device run, cloud deployment proof, or user-test result.
